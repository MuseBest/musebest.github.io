How to Start a Blog on Ghost in 2026

To start a blog on Ghost, you need to choose between the managed Ghost(Pro) service and self hosting the free Ghost software, then set up your publication, connect a domain, and publish your first post. Ghost is an open source publishing platform built for writers, newsletters, and independent publications. It is simpler than WordPress and it has memberships, newsletters, and search tools built in. This guide explains both routes in plain words, with honest costs, so you can pick the one that fits your skills and your budget.

Step 1: Decide if Ghost suits your blog

Ghost is a publishing platform, which is software that lets you write, publish, and send posts to readers. It was founded in 2013 with a focus on professional publishing for independent writers and journalists. It is built with Node.js, which is a way of running JavaScript on a server, and it is open source, which means anyone can read and use its code for free.

Ghost suits you if you want a clean writing editor, a built in newsletter, and paid memberships without adding many plugins. It suits writers, newsletter publishers, and small publications that want to charge readers for access. It suits you less if you want thousands of plugins, a shop, a forum, or a heavily customised site. WordPress offers far more plugins and themes, while Ghost offers fewer choices and a simpler setup. Our guide on how to start a blog on WordPress explains the WordPress route, and our guide on how to start a blog on Medium covers a free hosted option if you want no setup at all.

Ghost has no plugin system like WordPress. It has integrations instead, which are connections to other tools such as analytics, comments, and email services. Check that the tools you need work with Ghost before you commit. If your blog needs a feature Ghost does not offer, and no integration covers it, you may need WordPress instead.

Step 2: Choose Ghost(Pro) or self hosting

Ghost gives you two ways to publish. Ghost(Pro) is the official managed service. The Ghost team runs the server, applies updates, handles backups, and manages security for you. Self hosting means you install the free Ghost software on a server you rent and maintain yourself. The writing experience is the same either way, but the work and the cost are very different.

Decision Ghost(Pro) Self hosted Ghost
Setup Create an account and configure your publication Rent a server, install software, configure the server
Server work Handled by Ghost You manage updates, backups, and security
Monthly cost A subscription based on your member count Server cost plus domain and possibly email delivery
Control Less control over the server Full control over the server and the software
Best for Writers who want to write, not manage servers People who can manage a Linux server

Choose Ghost(Pro) if you want to write without operating a server. Choose self hosting if you want full control, you are comfortable with basic server work, or you want to avoid a monthly subscription that grows as your member list grows. There is no free Ghost(Pro) plan, so if your budget is zero, self hosting on a cheap server is the only Ghost route, and even that costs money for the server and the domain.

Step 3: Create your Ghost(Pro) publication

Ghost(Pro) is the shortest path to a live blog. Start by opening the Ghost website and choosing a plan. Plans are priced by member count, so a small list costs less than a large one. As of November 2026, the prices shown on Ghost's official pricing page are 18 US dollars per month for Starter, 29 US dollars per month for Publisher, and 199 US dollars per month for Business, all billed yearly, with a Custom plan priced on request. Prices change often, so confirm the current price before you pay.

Pick Starter if you want a personal blog or a free newsletter with up to 1,000 members. Pick Publisher if you want paid subscriptions, custom themes, and more staff users, because Starter does not include paid subscriptions. Pick Business if you run a team publication with higher limits and priority support. Every plan includes a free custom domain, a free SSL certificate, automatic updates, and unlimited email sends.

After you choose a plan, create your publication. Enter the publication name, the owner account details, and an initial site address. You can use a temporary Ghost address at first and connect your own domain later. Then complete the owner account with a strong, unique password. The owner account manages publication settings, staff access, and memberships, so protect it well.

Step 4: Or install Ghost on your own server

Self hosting is appropriate when you need control over the server or you want to run the open source software without a managed subscription. The software itself is free, but running it is not free: you still pay for the server, the domain, and possibly a separate email service for newsletters.

Ghost publishes official installation requirements, and they change over time, so check the current install guide before you start. The baseline in recent guides is a server with at least 1 GB of memory, a supported Ubuntu release, NGINX as the web server, a supported Node.js version, MySQL 8 as the database, and systemd to run Ghost as a service. Do not substitute a different database without checking current official Ghost support, because MariaDB support for production use has not always been confirmed.

The usual order is: rent a server, point your domain at it with a DNS record before you install, create a non-root user account for the installation, install Ghost-CLI, which is Ghost's command line installer, and run the installer. Ghost-CLI asks for your site address, database details, and service settings, and it can set up NGINX, the system service, and a free SSL certificate for you. After installation, open your site address and create the administrator account on the setup screen.

If any of that sounds unfamiliar, choose Ghost(Pro) instead. A failed self hosted install can cost you days, and a poorly maintained server can go offline or get hacked. Self hosting saves money only if your time is free and your server skills are solid.

Step 5: Connect a custom domain

A custom domain is your own web address, such as yourblog.com, instead of a free subdomain such as yourblog.ghost.io. A custom domain looks more professional, it is easier for readers to remember, and you keep it if you move platforms later. Ghost(Pro) includes a free custom domain on every plan.

To connect a domain, buy one from a domain registrar if you do not already own one. In your Ghost admin area, open the domain settings and enter your domain. Ghost will show you the DNS records to add. DNS records are settings at your registrar that tell the internet where your site lives. Add the records Ghost provides, then wait for them to take effect, which can take minutes or hours. Keep your temporary Ghost address working until the custom domain resolves correctly, and test the site in a private browser window before you share the address.

Use a short domain that is easy to spell and easy to say. Avoid hyphens and numbers. Check that the name is free on the social platforms you plan to use, because a matching handle makes your blog easier to find.

Step 6: Set up design, pages, and navigation

A new Ghost blog uses the default theme, which is called Casper. A theme is the template that controls how your site looks. Start with Casper or another official theme, and change it only when you know what you want to look different. On the Starter plan you can use official themes with their design settings, while custom themes need the Publisher plan or higher, as of November 2026.

Work through the settings in this order. First, set your publication title, description, logo, and icon. Keep the description short enough for search results and social previews. Second, set your timezone and language, so scheduled posts and dates show correctly. Third, create your essential pages: About, Contact, and Privacy Policy. Ghost ships with some of these pages already created, so edit them rather than starting from scratch. Fourth, set up navigation, which is the menu at the top of your site. Add only the links readers need at launch, such as Home, Archive, About, and Contact, and check every link works.

Use tags to organise your posts. A tag is a label you attach to a post, such as a topic name, and each tag gets its own archive page. Use a small number of broad tags, about three to seven, rather than a new tag for every post. Too many tags confuse readers and weaken your site structure.

Step 7: Turn on memberships and payments

Memberships are Ghost's strongest feature. Readers can sign up as free members to get your newsletter, and you can offer paid memberships for full access. In Ghost, your audience is divided into three groups: public visitors, free members, and paid members. You can lock a whole post, or part of a post, so only paid members can read it.

To take payments, connect Stripe, which is the payment service Ghost uses for memberships. Ghost charges 0 percent transaction fees on the Publisher, Business, and Custom plans, as of November 2026, which means Ghost takes no cut of your subscription income. Stripe still charges its own processing fee on each payment, so the amount you keep is less than the subscription price. Set your membership prices only after you have tested the payment flow with a real card, and test both a free signup and a paid signup before you announce them.

Do not enable paid memberships on day one. Publish free posts first, build a small audience, and learn what your readers value. A paywall on a blog nobody reads earns nothing. When you do add paid tiers, offer one or two simple options, such as a monthly price and a yearly price, and say clearly what paying members get. Our guide on how to monetise a blog with memberships explains membership pricing in more detail.

Step 8: Write and publish your first post

Open the Ghost editor and write a specific headline that describes what the reader will learn. Ghost's editor uses Markdown, which is a simple way of formatting text with plain characters, so you can write fast without reaching for toolbar buttons. Structure the post with short sections, descriptive subheadings, lists, and links where they help the reader.

Add media with care. Use images you have the right to use, add a feature image, and write alt text that describes each image. Set the post excerpt, which is the short summary shown in lists and search results, and set the URL slug, which is the short address for the post. Keep the slug stable once the post is published, because changing it breaks links.

Preview the post at desktop and mobile widths before you publish. Check the headline, the images, the links, and the subscription form. Then publish it or schedule it for a time your readers are online. Confirm your publication timezone first, so a scheduled post goes out when you expect. After you publish, open the live URL in a private browser window and check it as a reader would see it.

Plan your next posts before you promote the first one. A single post rarely brings lasting traffic. Aim for a small set of useful posts on one topic, publish on a steady schedule, and use your newsletter to bring readers back. Ghost(Pro) prices rise as your member count grows, so a large list costs more than a small one on the same plan. Check the current price on Ghost's pricing page before you pay, because prices change and the figures above are from November 2026. Self hosting looks cheaper at first, but add the value of your own time for updates, backups, and fixing problems, and the gap shrinks fast.

Expect a slow start. A new blog takes months to build an audience, and paid memberships take longer still, because readers pay only after they trust your work. Publish useful free posts for several months before you judge whether Ghost is working for you. If you need income fast, Ghost is the wrong choice, because no platform pays you before readers arrive.

Worked example

Example only: these numbers are not typical results. Imagine your Ghost blog has 200 free members after six months. Suppose 5 percent of them become paying members. That is 200 times 0.05, which equals 10 paying members. Suppose each paying member pays 5 US dollars per month. That is 10 times 5, which equals 50 US dollars per month in gross subscription income. Ghost charges a 0 percent transaction fee on the Publisher plan, so Ghost takes nothing from that 50 US dollars. Stripe still charges its own processing fee on each payment, so the amount that reaches your bank is less than 50 US dollars. If only 2 percent convert instead of 5 percent, that is 200 times 0.02, which equals 4 paying members, times 5 US dollars, which equals 20 US dollars per month before fees. This shows why growing the free list matters more than setting a high price.

Common mistakes

  • Choosing self hosting to save money, then spending days fixing a server instead of writing posts.
  • Picking the Starter plan and then finding out it does not include paid subscriptions.
  • Turning on a paywall before anyone reads the blog, which earns nothing and hides your best work.
  • Using a new tag for every post instead of a small set of broad tags that organise the site.
  • Skipping the domain setup and launching on a free subdomain that looks unprofessional.
  • Forgetting to test email delivery, so newsletters go to spam or never arrive.
  • Publishing one post and then going quiet for months, which loses the few readers you gained.

Risks and scams to watch for

Self hosting carries real maintenance risk. Ghost releases updates often, and a self hosted site that is not updated can develop security problems. One widely reported flaw in late 2026 affected older Ghost versions and was fixed in a later release, which shows why updates matter. If you self host, set a monthly reminder to update Ghost, back up your database and your images, and check that your backups restore correctly. Ghost(Pro) handles updates and backups for you, which is the main reason it costs more.

Email delivery is a common trap for self hosted blogs. Running a website does not automatically give you reliable bulk email delivery. You may need a separate email service, and you must verify your sending domain with that service and test delivery to more than one mailbox before you announce your newsletter. Check spam folders and confirm the sender address is correct.

Watch for fake Ghost services and fake support messages. Only sign up at the official Ghost website, and never share your admin password or your Stripe details with anyone who contacts you first. Ghost will not ask for your password by email. If a message claims your blog will be deleted unless you pay, treat it as a scam and check your account by logging in directly.

Frequently asked questions

Is Ghost free?

The Ghost software is free and open source, so you can install it on your own server without paying Ghost. Running it still costs money for the server, the domain, and possibly email delivery. Ghost(Pro), the official managed hosting, is a paid service with no free plan, and its prices start at 18 US dollars per month billed yearly, as of November 2026.

Is Ghost better than WordPress for blogging?

It depends on what you need. Ghost is simpler, faster to learn, and has memberships and newsletters built in. WordPress offers far more plugins and themes, and it suits sites that need a shop, a forum, or heavy customisation. Choose Ghost if you want to write and send newsletters with little setup, and choose WordPress if you need features Ghost does not offer.

Can I make money with a Ghost blog?

Yes, through paid memberships, tips, affiliate links, sponsored content, and digital products. Ghost takes a 0 percent transaction fee on paid subscriptions on the Publisher plan and higher, as of November 2026, but Stripe charges its own processing fee. You can also show display ads, although ad networks are not built in on the Starter plan, and Google pays AdSense publishers once earnings reach its payment threshold, which you can check on Google's AdSense payment thresholds page. Income takes months to build, because readers pay only after they trust your work.

Do I need technical skills to use Ghost?

No, if you use Ghost(Pro), which needs no server skills. You need basic computer skills, a domain name, and patience to learn the editor. Self hosting needs basic Linux skills, including working with a server, a database, and a web server, so most beginners should choose Ghost(Pro).

Can I move my blog from WordPress or Medium to Ghost?

Yes, Ghost has import tools and guides for moving content from WordPress, Medium, and other platforms. Export your content from the old platform, import it into Ghost, and check every post for broken images, links, and formatting. Set up redirects from your old URLs to your new ones, so readers and search engines find the moved posts.

How long does it take to set up a Ghost blog?

A Ghost(Pro) blog can be live in under an hour, including the domain setup, if your domain records update quickly. A self hosted install takes longer, often several hours for a first attempt, plus extra time if anything goes wrong. Either way, allow a full day for design, pages, and your first post.

Conclusion

To start a blog on Ghost, pick the route that fits your skills: Ghost(Pro) if you want to write without managing a server, or self hosting if you want full control and you can maintain a server. Connect a custom domain, set up your design and pages, publish useful free posts first, and add paid memberships only once readers trust your work. Check the current prices on Ghost's pricing page before you pay, because they change and they rise with your member count.
